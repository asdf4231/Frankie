# Frankie 测试

安装测试与 Web 依赖后运行：

```bash
uv sync --extra web --extra dev
uv run pytest
```

测试使用临时目录和模拟模型响应，不调用真实 LLM API，也不修改用户数据。

## 覆盖范围

- Web 问答提示、课程页面浏览和引用解析
- Wiki、讲义、FAQ 之间的链接与聊天引用解析到同一标题锚点（`FRANKIE_AUDIT_COURSE_LINKS=1` 时检查真实课程库的全部链接）
- 运行时目录和用户数据隔离
- 结构化检索工具调用和上下文续接
- 对话历史、附件、流式失败和取消后的持久化
- 长对话压缩时的工具事务完整性
- 学情接口的管理员鉴权、学生历史只读访问、分页与附件路径边界
- 全班摘要的增量时间边界、并发生成、失败重试、原子保存和长输入分批分析
